AutoTokenizer - teeb tekstist numbrid, mida mudel mõistab.
    Näiteks: "See on ajaleht" -> [101, 2345, 123, 4567, 102]
    Need on token id-d.

AutoModelForSequenceClassification - laeb BERT mudeli klassifitseerimiseks.
    See tähendab: neuronvõrgu arhitektuur, pretrained kaalud + klassifikaatori kiht.
    num_labels=2 -> mudel tagastab 2 klassi (0 või 1).
    NB: AutoModel annab ainult embeddingud (last_hidden_state),
        AutoModelForSequenceClassification annab otse logits väljundi.

test_model_setupi tokeniseerimise näide:
    inputs = tokenizer(text, return_tensors="pt", truncation=True, padding=True)
    tekst: "See on näidistekst..." -> tokenid: ["See", "on", "näidis", "tekst", ...] --
    -> token id-d: [101, 3452, 233, 5678, ...] -> PyTorch tensor: tensor([[101, 3452, ...]])

test mudeli väljundi selgitus:
    input_ids kuju: torch.Size([1, 11]) -> [batch_size, token_count], ehk see on 1 tekst ja 11 tokenit.
    logits kuju: torch.Size([1, 2]) -> [batch_size, num_labels], ehk 1 tekst, 2 klassi skoor.
    Näiteks: tensor([[-0.3902, -0.0009]]) -> klass 0 skoor: -0.3902, klass 1 skoor: -0.0009

KOMMENTAAR: Detailsemalt kirjeldades, meie eesmärk on leida artikli piirid, BERT annab tekst → tähendusvektorid
            siis lisame väikse klassifikaatori: vektor → kas artikli algus?, näiteks 0 = ei, 1 = jah.

PIPELINE:
Meie lõplik pipeline hakkab välja nägema nii:

tekst
 ↓
tokenizer
 ↓
BERT
 ↓
embeddingud
 ↓
classifier
 ↓
artikli piir

Eeltöötluse reeglid:
- üks treeningnäide = tekstiplokk/lõik
- labelid = 1 artikli algus, 0 mitte
- formaat = JSONL
Kohustuslikud väljad:
id – treeningnäite identifikaator
text - tekstiploki sisu
label – märgend (0 või 1)
Võimalikud lisaväljad:
source - kust see tekst pärineb ("source": "postimees_1935_03_12")
page - mis leheküljelt see tekst tuli ("page": 3)
article_id - millisesse artiklisse see lõik kuulub ("article_id": "article_1")

Näiteks:
{"id": "ex1", "text": "RIIGIKOGUS ARUTATI EILE UUT SEADUST", "label": 1}
{"id": "ex2", "text": "Arutelu kestis hiliste õhtutundideni.", "label": 0}

dataset.py - ArticleDataset:
    Ühendab load_jsonl() väljundi tokenizeriga.
    Pärib torch.utils.data.Dataset klassist.
    MAX_LENGTH = 512 (EstBERT maksimaalne sisendpikkus).
    Tagastab iga näite kohta:
        input_ids      - tokeniseeritud tekst arvudena, kuju [512]
        attention_mask - 1 = päris tekst, 0 = padding, kuju [512]
        labels         - 0 või 1, torch.long formaadis
    Batchi näide (batch_size=4):
        input_ids kuju:      torch.Size([4, 512])
        attention_mask kuju: torch.Size([4, 512])
        labels kuju:         torch.Size([4])
