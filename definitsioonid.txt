# =============================================================================
# PROJEKT: EstBERT artikli piiride tuvastamine
# =============================================================================
#
# EESMÄRK:
#   Treenida EstBERT mudel, mis tuvastab automaatselt artikli piirid
#   digiteeritud eesti ajalehetekstides. Mudel klassifitseerib iga
#   tekstiploki: 1 = artikli algus, 0 = artikli jätk.
#
# =============================================================================
# PIPELINE (run_pipeline.py jooksutab kõik järjest)
# =============================================================================
#
#   1. build_large_dataset.py  →  large_triplet_dataset.jsonl
#   2. split_dataset.py        →  train / val / test
#   3. train.py                →  models/final_model/
#   4. evaluate.py             →  evaluation_report.json
#   5. inference.py            →  segmenteeritud väljundfail
#
# Sisend:  data/raw/segmented/*.txt  (segmenteeritud ajalehed, üks artikkel rea kohta)
# Väljund: data/output/              (ennustused, debug, raport, graafikud)
#
# =============================================================================
# PIPELINE SELGITUS
# =============================================================================
#
# MIKS TRIPLETID?
#   Iga treeningnäide koosneb kolmest tekstiplokist: {prev, curr, next}.
#   BERT näeb konteksti mõlemalt poolt — mis oli enne, mis tuleb järgmisena.
#   Artikli esimese chunki puhul on prev="", mis on BERT-ile tugev signaal
#   et tegemist on label=1-ga.
#
#   BERT sisend: "[prev tekst] [SEP] [curr tekst] [SEP] [next tekst]"
#
# MIKS WEIGHTED LOSS?
#   Andmestik on tasakaalustamata: ~10% label=1, ~90% label=0.
#   Ilma kaaluta õpib mudel kõik label=0-ks ennustama (accuracy=0.9 aga F1=0).
#   WeightedCrossEntropyLoss karistab label=1 vahelejätmist rohkem.
#   Kaal arvutatakse automaatselt: class_1_weight = num_zeros / num_ones
#
# MIKS THRESHOLD TUNING?
#   BERT väljundab tõenäosuse (0.0 - 1.0), mitte otse labeli.
#   Default threshold=0.5 ei pruugi olla parim tasakaalustamata andmestikul.
#   evaluate.py leiab valideerimisandmestikul parima threshold'i (F1 järgi).
#   Leitud threshold'i kasutatakse inference.py --threshold argumendina.
#
# =============================================================================
# FAILIDE SELGITUS
# =============================================================================
#
# src/
#   text_cleaner.py   — kõik teksti puhastamise loogika:
#                        clean_html(), extract_p_tags(), clean_text(),
#                        is_layout_noise(), protect_abbreviations(),
#                        split_into_sentences()
#   dataset.py        — load_jsonl(), NewsDataset, build_triplet_input()
#                        laeb JSONL andmestiku ja annab BERT-ile õiges formaadis
#   model_setup.py    — load_model(): laeb EstBERT tokenizeri ja mudeli
#
# scripts/
#   build_large_dataset.py  — ehitab treeningandmestiku segmenteeritud failidest
#   split_dataset.py        — jagab andmestiku train/val/test (artikli kaupa!)
#   train.py                — treenib EstBERT mudeli WeightedTrainer'iga
#   evaluate.py             — hindab mudelit, leiab parima threshold'i
#   inference.py            — kasutab mudelit uutel tekstidel (sliding window)
#   run_pipeline.py         — jooksutab kõik sammud järjest
#
# =============================================================================
# ANDMESTIKU FORMAAT
# =============================================================================
#
# Sisendfail (data/raw/segmented/*.txt):
#   Iga rida = üks artikkel
#   Formaat: article_id<TAB><p>tekst</p><p>tekst</p>
#   Näide:   estdagbladet20110316.1.1    <p>Eesti oli majanduskasvult...</p>
#
# Treeningnäide (JSONL):
#   {
#     "id":    "estdagbladet20110316.1.1_0",
#     "prev":  "",                        ← tühi = artikli algus (label=1 signaal)
#     "curr":  "Eesti oli majanduskasvult...",
#     "next":  "Rootsi majandus kasvas...",
#     "label": 1
#   }
#
# Labelid:
#   1 = artikli algus (esimene chunk artiklist)
#   0 = artikli jätk (kõik järgnevad chunkid)
#
# =============================================================================
# MUDEL
# =============================================================================
#
# AutoTokenizer:
#   Teeb tekstist arvud mida mudel mõistab.
#   "See on ajaleht" → [101, 2345, 123, 4567, 102]
#
# AutoModelForSequenceClassification (EstBERT):
#   num_labels=2 → mudel tagastab 2 klassi skoori (logits)
#   Näide: tensor([[-0.39, -0.001]]) → klass 0: -0.39, klass 1: -0.001
#   NB: AutoModel annab ainult embeddingud,
#       AutoModelForSequenceClassification annab otse logits väljundi.
#
# Mudeli pipeline:
#   tekst → tokenizer → EstBERT → embeddingud → classifier → label (0/1)
#
# NewsDataset tagastab iga näite kohta:
#   input_ids      — tokeniseeritud tekst arvudena, kuju [512]
#   attention_mask — 1 = päris tekst, 0 = padding, kuju [512]
#   labels         — 0 või 1, torch.long formaadis
#
# =============================================================================
# HÜPERPARAMEETRID
# =============================================================================
#
#   BATCH_SIZE = 4       — mitu näidet korraga (GPU mälu piirang)
#   EPOCHS = 5           — mitu korda mudel kogu andmestiku läbi vaatab
#   LEARNING_RATE = 2e-5 — kui kiiresti mudel õpib (standard BERT fine-tuning)
#   MAX_LENGTH = 512     — EstBERT maksimaalne sisendpikkus tokenites
#
# =============================================================================
# HINDAMISMETOODIKA
# =============================================================================
#
#   Peamine mõõdik: F1-score label=1 kohta (mitte accuracy!)
#   Põhjus: accuracy on petlik tasakaalustamata andmestikul
#           (0.9 accuracy saab lihtsalt kõike label=0 ennustades)
#
#   Confusion matrix: [[TN, FP], [FN, TP]]
#     TN — õigesti ennustatud "mitte algus"
#     FP — valesti ennustatud "algus" (tegelikult jätk)
#     FN — vahele jäetud artikli algus (kriitiline viga)
#     TP — õigesti leitud artikli algus
#
# =============================================================================
